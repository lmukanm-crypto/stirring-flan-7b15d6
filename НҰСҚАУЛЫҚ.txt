ҚҰҚЫҚТЫҚ ТАҢДАУ — NETLIFY ҮШІН ТҮЗЕТІЛГЕН НҰСҚА

1. Бастау батырмасы міндетті түрде тапсырманы ашады, аты-жөні енгізіледі.
2. Егер сайт тек index.html файлын жүктеп жариялаған болсаңыз, оқушы ойынды толтыра алады, бірақ жауап МҰҒАЛІМГЕ ЖІБЕРІЛМЕЙДІ. Экранда ескерту шығады.
3. Барлық телефонның нәтижелерін ортақ экранға жіберу үшін netlify/functions/api.mjs қызметі және @netlify/blobs кітапханасы орнатылуы керек.
4. Ұсынылатын жариялау: GitHub-та репозиторийге архив ішіндегі барлық файлды жүктеп, Netlify → Add new project → Import from Git арқылы осы репозиторийді қосыңыз. Сайт Netlify арқылы құрастырылып серверлік функциялар орнатылады.
5. Netlify → Project configuration → Environment variables → ADMIN_PIN құпия кодын қосыңыз (мысалы, тек мұғалім білетін 6 цифр). Жаңа deploy жасаңыз.
6. Басты сайт: https://сіздің-сайт.netlify.app/ ; оқушы QR сілтемесі https://сіздің-сайт.netlify.app/?student=1
7. Ең алдымен екі телефонмен тексеріңіз: басты экранды бірінен ашып, екіншісінен жауап жіберіңіз. Нәтиже шамамен 3 секунд сайын шығады.
8. Оқушылардың аты-жөні мен жазбалары онлайн сақталады; мектеп деректерінің құпиялылық талаптарын ескеріңіз. Нақты толық аты-жөнін міндетті етпей, оқушы коды немесе қысқа ат пайдалануға болады.
ЕСКЕРТУ: zip файлын жай Netlify Drop арқылы салу серверлік функциялардың орнатылуына кепіл бермейді. Git арқылы жариялаңыз.
